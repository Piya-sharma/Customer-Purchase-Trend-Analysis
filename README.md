# Customer Purchase Trend Analysis

## Project Overview
This project focuses on analyzing customer purchase data using Python to identify revenue trends, purchasing patterns, and customer behavior. It includes data cleaning and Exploratory Data Analysis (EDA) using Pandas and Matplotlib.

## Objectives
- Clean and prepare customer purchase data.
- Analyze revenue across product categories and regions.
- Explore monthly revenue trends.
- Examine payment methods and customer types.
- Identify the top 10 customers by revenue.

## Tools & Technologies
- **Python** — Data analysis
- **Pandas** — Data cleaning and manipulation
- **Matplotlib** — Data visualization
- **Jupyter Notebook** — Analysis and documentation

## Project Files

- **Python Analysis Notebook:** [Open Notebook](./Python%20Analysis%20Project%20%281%29.ipynb)
- **Dataset:** [View CSV Dataset](./Customer_Purchase_Trend_DirtyData.csv)

## Analysis Performed
- Data cleaning, including missing values and duplicate records
- Product category-wise revenue analysis
- Region-wise revenue analysis
- Monthly revenue trends
- Payment mode distribution
- Customer type-wise revenue analysis
- Top 10 customers by revenue


## Key Learnings
- Data cleaning and preprocessing using Pandas
- Exploratory Data Analysis (EDA)
- Revenue and customer behavior analysis
- Creating visualizations to communicate insights

## How to Run the Project
1. Download the notebook and CSV dataset.
2. Open the notebook using Jupyter Notebook or Google Colab.
3. Keep the CSV dataset in the same working directory as the notebook.
4. Run the notebook cells to reproduce the analysis.
